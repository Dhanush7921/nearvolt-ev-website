Uses the existing `android/keystore.properties` (or NV_KEYSTORE_* env vars). No new key is generated.

## 2. Verify before sharing
```powershell
$bt = (Get-ChildItem "$env:LOCALAPPDATA\Android\Sdk\build-tools" | Sort-Object Name | Select-Object -Last 1).FullName
& "$bt\apksigner.bat" verify --print-certs app\build\outputs\apk\prod\release\app-prod-arm64-v8a-release.apk
#  -> SHA-256 digest must equal the release SHA-256 registered in Firebase (Project settings + App Check)
& "$bt\aapt2.exe" dump badging app\build\outputs\apk\prod\release\app-prod-arm64-v8a-release.apk | Select-String "versionCode|package:"
#  -> package: name='com.nearvolt.ev' versionCode='2' versionName='1.1.0'
```
Install V1.1 over V1.0 normally (same package, same key, higher versionCode). Users don't need ADB or debug tokens.

## 3. Backend deployment (needs owner approval)
V1.1 adds the session PIN. **A V1.0 app cannot send a PIN**, so once this backend is live V1.0 hosts can't start charging.
Deploy in this order:
1. Share the V1.1 APK with all pilot hosts and drivers, and confirm they have installed it.
2. Merge `upgrade/v1.1-premium-zero-cost` into `production/v1` (Render deploys automatically).
3. Admin dashboard → Settings → set **Minimum supported version code = 2** and **Latest = 2**. V1.0 users then see the update screen instead of a broken flow.

The new admin analytics query uses the existing `requests (status, createdAt)` index, so no index deploy is needed.

## 4. Rollback
* App: reinstall the V1.0 APK only after rolling back the backend. Android blocks a downgrade over a newer versionCode, so uninstall V1.1 first.
* Backend: in Render, use Deploys → "Rollback" to the last V1.0 deploy, or `git revert` the merge on `production/v1`. Set the minimum version code back to 1.
* Data: V1.1 only adds optional fields to requests (`batteryPercent`, `pin`, `pinReissues`). V1.0 ignores them, so nothing needs migrating.

## 5. Zero-cost status
Maps: MapLibre + OpenFreeMap (no key). Directions: Google Maps URL (no key). Charts: inline SVG. No paid APIs were added.
Skipped because they cost money: road-distance/routing APIs, Places autocomplete, paid SMS (phone login stays behind its existing flag), Razorpay, custom domain, Firestore TTL (Blaze).
